📌 About This Repository

This repository contains a collection of 12 Java practical programs developed as part of the Object Oriented Programming with Java course during my 3rd semester of B.Tech CSE.

These practicals demonstrate the implementation of fundamental and advanced Java programming concepts, including:

- Object-Oriented Programming (OOP)
- Arrays and Multithreading
- Graphical User Interface (GUI) Development
- Abstract Window Toolkit (AWT)
- Java Swing
- Client-Server Communication
- Remote Method Invocation (RMI)
- JavaBeans
- Java Database Connectivity (JDBC)
- MySQL Database Operations
- CRUD Operations

Each practical is organised into a separate folder containing its source code, README documentation and other required files.

The main objective of this repository is to document my practical learning, improve programming skills and gain hands-on experience in Java application development.

🎯 Objectives

- To understand Java programming fundamentals.
- To implement object-oriented programming concepts.
- To develop GUI-based applications using AWT and Swing.
- To understand multithreading and networking.

- To implement database operations using SQL queries.
- To develop practical programming and problem-solving skills.
