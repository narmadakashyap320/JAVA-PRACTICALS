## Practical 01: Matrix Multiplication

# Aim

To write a Java program for matrix multiplication using InputStreamReader and BufferedReader classes for input and output operations.

# Technologies Used

- Java
- Java I/O (Input/Output)

# Concepts Covered

- Two-dimensional arrays
- Matrix multiplication
- Nested for loops
- InputStreamReader
- BufferedReader
- Conditional statements

# Tools Required

- JDK (Java Development Kit)
- VS Code / IntelliJ IDEA / Eclipse
- Command Prompt or Terminal

# Files Included

- ` MatrixMultiplication.java` – Main Java source code.
- `output.png` – Program execution screenshot.

# Working Procedure

1. Accept the dimensions of two matrices from the user.
2. Check whether matrix multiplication is possible.
3. Read the elements of both matrices.
4. Multiply the corresponding rows and columns.
5. Display the resultant matrix.

# Expected Outcome

The program successfully multiplies two matrices and displays the resultant matrix.

# Learning Outcomes

- Understand matrix operations in Java.
- Learn how to use two-dimensional arrays.
- Perform user input operations using BufferedReader.
- Develop logical thinking using nested loops.
