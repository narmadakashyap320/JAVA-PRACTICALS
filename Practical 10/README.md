# Practical 10: JavaBean for Addition of Two Numbers

# Aim

To create a JavaBean component for performing the addition of two numbers.

# Technologies Used

- Java
- JavaBeans

# Concepts Covered

- JavaBean architecture
- Encapsulation
- Serializable interface
- Getter and Setter methods
- Constructors
- Object-oriented programming

# Tools Required

- JDK
- VS Code / Eclipse / IntelliJ IDEA
- Command Prompt or Terminal

# Files Included

- `AdditionBean.java` – JavaBean component.
- `BeanAdditionDemo.java` – Main program to use the Bean.
- `output.png` – Program execution screenshot.

# Working Procedure

1. Create a JavaBean class.
2. Declare two private integer variables.
3. Create a no-argument constructor.
4. Define getter and setter methods.
5. Create a method to calculate the sum.
6. Create a main class to access the Bean.
7. Accept two numbers and display their addition.

# Expected Outcome

The JavaBean component successfully adds two numbers and displays the calculated sum.

# Learning Outcomes

- Understand JavaBean components.
- Learn encapsulation in Java.
- Understand getter and setter methods.
- Develop reusable Java components.
