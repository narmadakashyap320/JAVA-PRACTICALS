## Practical 03: Calculator using AWT

# Aim

To design and implement a calculator application using AWT controls provided by Java.

# Technologies Used

- Java
- AWT (Abstract Window Toolkit)

# Concepts Covered

- GUI programming
- Frame
- Button
- TextField
- ActionListener
- ActionEvent
- Event handling
- Arithmetic operations

# Tools Required

- JDK
- VS Code / Eclipse / IntelliJ IDEA
- Command Prompt or Terminal

# Files Included

- "AWTCalculator.java" – Main calculator program.
- "output.png" – Calculator application screenshot.

# Working Procedure

1. Create a Frame using AWT.
2. Add a TextField to display input and results.
3. Create buttons for numbers and arithmetic operators.
4. Implement ActionListener to handle button clicks.
5. Perform addition, subtraction, multiplication and division.
6. Display the calculated result.

# Expected Outcome

A graphical calculator window is displayed with numeric and arithmetic buttons. The user can perform basic mathematical operations.

# Learning Outcomes

- Understand GUI development using AWT.
- Learn event handling in Java.
- Understand the use of buttons and text fields.
- Implement basic arithmetic operations through a graphical interface.
