## Practical 09: Student Registration Portal using JDBC

# Aim

To develop a small student registration portal containing a registration form and store student information in a MySQL database using JDBC.

# Technologies Used

- Java
- JDBC
- MySQL
- Java Swing

# Concepts Covered

- GUI form development
- JDBC connectivity
- Database creation
- SQL INSERT command
- PreparedStatement
- Database management
- Exception handling

# Tools Required

- JDK
- MySQL Server 8.0
- MySQL Workbench / MySQL Command Line Client
- MySQL Connector/J
- VS Code / Eclipse

# Files Included

- `StudentRegistrationPortal.java` – Student registration application.
- `DBConnection.java` – Database connectivity class.
- `database.sql` – Database and student table creation queries.
- `output.png` – Registration form screenshot.

# Working Procedure

1. Create a database named java_practicals.
2. Create a table named students.
3. Design a registration form containing student name, email and course fields.
4. Accept information from the user.
5. Establish a JDBC connection.
6. Insert the student details into the database.
7. Display a registration success message.

# Expected Outcome

The student registration form accepts student details and successfully stores them in the MySQL database.

# Learning Outcomes

- Understand student registration systems.
- Learn JDBC database connectivity.
- Perform insertion operations using SQL.
- Develop database-driven Java applications.
