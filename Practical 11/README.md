## Practical 12: Database CRUD Operations using JDBC

# Aim

To reuse the student registration form and perform basic database operations (CRUD) using JDBC in Java.

# Technologies Used

- Java
- JDBC
- MySQL
- Java Swing
- SQL

# Concepts Covered

- CRUD operations
- Database connectivity
- JDBC architecture
- SQL INSERT command
- SQL SELECT command
- SQL UPDATE command
- SQL DELETE command
- PreparedStatement
- ResultSet
- Exception handling
- GUI development

# Tools Required

- JDK
- MySQL Server 8.0
- MySQL Workbench / MySQL Command Line Client
- MySQL Connector/J
- VS Code / Eclipse

# Files Included

- `StudentCRUD.java` – Main CRUD application.
- `DBConnection.java` – Database connectivity class.
- `database.sql` – Database and table creation queries.
- `output.png` – CRUD application screenshot.

# Working Procedure

1. Create

Insert new student records into the database using the INSERT command.

2. Read

Retrieve and display existing student records using the SELECT command.

3. Update

Modify existing student information using the UPDATE command.

4. Delete

Remove student records from the database using the DELETE command.

# Expected Outcome

The application successfully performs all four CRUD operations on student records stored in the MySQL database.

# Learning Outcomes

- Understand CRUD operations.
- Learn advanced JDBC concepts.
- Perform database insertion, retrieval, modification and deletion.
- Understand SQL queries and database management.
- Develop a database-driven Java application.
