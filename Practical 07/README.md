## Practical 07: Name and Password Form using Applet

# Aim

To create a form containing name and password fields using Java Applet as a container.

# Technologies Used

- Java
- Java Applet
- AWT
- HTML

# Concepts Covered

- Applet programming
- TextField
- Label
- Button
- GridLayout
- ActionListener
- Event handling
- Password masking

# Tools Required

- JDK 8
- VS Code / Eclipse
- AppletViewer

# Files Included

- `LoginFormApplet.java` – Java Applet source code.
- `index.html` – HTML file for loading the Applet.
- ` output.png` – Login form screenshot.

# Working Procedure

1. Create an Applet using the Applet class.
2. Add name and password input fields.
3. Add a Submit button.
4. Use setEchoChar() to hide password characters.
5. Implement ActionListener to handle form submission.
6. Display a message after submission.

# Expected Outcome

A graphical form is displayed with name and password fields. The user can enter the details and submit the form.

# Learning Outcomes

- Understand Applet programming.
- Learn form creation using AWT.
- Understand event handling.
- Learn password masking in Java.

# Note

Java Applets are obsolete and are not supported by modern browsers. JDK 8 with AppletViewer is required for the traditional demonstration.
