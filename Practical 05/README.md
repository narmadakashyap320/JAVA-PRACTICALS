## Practical 05: Notepad Application using Swing

# Aim

To develop a Notepad-like application using Java Swing components.

# Technologies Used

- Java
- Java Swing
- Java I/O

# Concepts Covered

- GUI development
- JFrame
- JTextArea
- JMenuBar
- JMenu
- JMenuItem
- JFileChooser
- File handling
- Event handling

# Tools Required

- JDK
- VS Code / Eclipse / IntelliJ IDEA

# Files Included

- `SimpleNotepad.java` – Main Notepad application.
- ` output.png` – Notepad application screenshot.

# Working Procedure

1. Create a graphical window using JFrame.
2. Add a JTextArea for writing and editing text.
3. Create a File menu.
4. Add New, Open, Save and Exit options.
5. Use JFileChooser to select files.
6. Implement file reading and writing operations.

# Expected Outcome

A simple Notepad application is created where users can write, edit, open and save text files.

# Learning Outcomes

- Understand Java Swing components.
- Learn GUI application development.
- Perform file handling operations.
- Understand event-driven programming.
