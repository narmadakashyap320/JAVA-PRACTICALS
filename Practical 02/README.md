## Practical 02: String Animation using Multithreading

# Aim

To write a Java program to animate a string on an Applet using the concept of multithreading.

# Technologies Used

- Java
- Java Applet
- HTML
- AWT (Abstract Window Toolkit)

# Concepts Covered

- Multithreading
- Thread class
- Runnable interface
- Applet programming
- Graphics class
- Animation
- Repaint() method

# Tools Required

- JDK 8
- VS Code / Eclipse
- AppletViewer
- Web browser (only for understanding the HTML structure; modern browsers do not support Java Applets)

# Files Included

- `StringAnimationApplet.java` – Java animation program.
- `index.html` – HTML file to load the Applet.
- `output.png` – Animation output screenshot.

# Working Procedure

1. Create an Applet using the Applet class.
2. Implement the Runnable interface.
3. Create a thread to control string movement.
4. Update the position of the string continuously.
5. Use the repaint() method to refresh the screen.
6. Display the moving string.

# Expected Outcome

A moving text message appears inside the Applet window and continuously moves across the screen.

# Learning Outcomes

- Understand the concept of multithreading.
- Learn thread creation and execution.
- Understand basic Java Applet programming.
- Learn graphics-based animation in Java.
